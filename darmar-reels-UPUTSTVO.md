# Darmar Reels 1.0.0

Privremeni paket za instalaciju na darmardekor.rs. ZIP i ovo uputstvo biće uklonjeni iz aktuelne grane po isteku dogovorenog perioda.

1. Preuzmite darmar-reels-1.0.0.zip.
2. WordPress: Dodaci → Dodaj novi → Otpremi dodatak → Instaliraj → Aktiviraj.
3. Podešavanja → Darmar Reels. Za automatski režim unesite dugoročni Instagram User token (Instagram API with Instagram Login, instagram_business_basic). Token ne objavljujte u repozitorijumu.
4. Na početnu dodajte [darmar_reels] ili uključite shortcode u postojeći šablon.

Podrazumevano 3 najnovija i 3 dnevno nasumična starija Reelsa, bez ponavljanja. Ručni unos linkova radi bez API tokena. Detaljno uputstvo i ograničenja nalaze se u ZIP-u.
